## 二、实现清单

### 2.1 核心文件

#### pkg/executor/executor.go（P0-E-04）
**功能**：Executor 接口定义
```go
type Executor interface {
	Submit(ctx context.Context, task *model.Task) error
	Cancel(ctx context.Context, taskID string) error
	Stop() error
}
```

**关键规则**：
- Engine 只信 ExecutorResultEvent + UDS，不信"调用成功假设"
- Submit 返回 nil 不代表下单成功，只代表请求已发送

#### pkg/executor/ws_executor.go（P0-E-04）
**功能**：TradeWS 执行器实现
- `Submit()`: 将 Task 转换为 TradeWS 请求
- `buildRequest()`: 根据 TaskType 构造请求参数
- `sendExecutorResult()`: 回流 ExecutorResultEvent 到 Engine
- `Cancel()`: 取消 pending 任务

**双保险闭环**：
```
Task → TradeWS.SendRequest()
  ↓
TradeWSResponse → ExecutorResultEvent
  ↓
Engine.eventCh → handleExecutorResult()
  ↓
等待 UDS 的 OrderUpdateEvent 确认
```

#### pkg/engine/planner.go（P0-E-06）
**功能**：GapScan 缺口扫描
- `GapScan()`: 主扫描函数
- `calcWindowRange()`: 计算窗口范围
- `needPlaceEntry()`: 判断是否需要放置 Entry
- `needPlaceTP()`: 判断是否需要放置 TP
- `generatePlaceEntryTask()`: 生成 placeEntry 任务
- `generatePlaceTPTask()`: 生成 placeTP 任务

**扫描规则**：
1. 区间外：Entry全撤（TODO）

3. 区间内缺口立即补齐

### 5.3 GapScan 规则（P0-E-06）
```go
// Entry 缺口
func needPlaceEntry(level *model.LevelState) bool {
	return level.Entry.State == model.OrderStateNone ||
		level.Entry.State.IsTerminal() // FILLED/CANCELED/REJECTED
}

// TP 缺口
func needPlaceTP(level *model.LevelState) bool {
	return level.Entry.State == model.OrderStateFilled &&
		(level.TP.State == model.OrderStateNone || level.TP.State.IsTerminal())
}
```
