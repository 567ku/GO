## 二、实现清单

### 2.1 核心文件

#### pkg/engine/clid.go（P0-E-03）
**功能**：CLID解析与level查找
- `ParseCLID()`: 解析 clientOrderId 为 (purpose, levelID, cycle)
- `FindLevelByID()`: 查找指定levelID的level
- `FindOrCreateLevel()`: 查找或创建level
- `GetOrderSlot()`: 获取指定level的订单槽

**CLID格式**：
```
Entry: {prefix}:E:{levelId}:{cycle}
TP:    {prefix}:T:{levelId}:{cycle}
```

#### pkg/engine/engine.go（P0-E-01 + P0-E-02）
**核心结构**：
```go
type Engine struct {
	state   *model.GridStateSnapshot  // 唯一状态源
	eventCh chan model.EngineEvent    // 事件入口
	mode    model.EngineMode          // RUNNING/FREEZE/RECONCILING
	// ...
}
```

**关键方法**：
- `Run(ctx)`: 单写者事件循环
- `dispatch(ev)`: 事件分发器
- `SetMode(mode)`: 设置引擎模式
- `CanSubmitWriteTask()`: 写闸门判断
- `handlePriceTick()`: 处理价格tick
- `handleOrderUpdate()`: 处理订单更新（CLID映射）
- `handleWSState()`: 处理WS状态（Freeze机制）

## 五、关键设计亮点

### 5.1 单写者原则（P0-E-01）
```go
// ✅ 允许：Engine.Run() 内通过 handleXXX() 修改状态
func (e *Engine) handleOrderUpdate(ev model.OrderUpdateEvent) {
	e.state.Market.LastPriceTicks = ev.PriceTicks  // OK
}

// ❌ 禁止：外部直接修改state
// engine.state.Market.LastPriceTicks = 123  // 不允许
```

### 5.2 状态机闸门（P0-E-02）
```go
// 写闸门逻辑
func (e *Engine) CanSubmitWriteTask() bool {
	return e.mode == model.EngineModeRunning
}

// 状态转换规则
RUNNING → FREEZE:       WS断线
FREEZE → RECONCILING:   WS重连
RECONCILING → RUNNING:  对账通过（TODO）
```

### 5.3 CLID映射（P0-E-03）
```go
// 双向映射
CLID → (purpose, levelID, cycle) → Level → OrderSlot
OrderUpdate → CLID解析 → Level查找 → Slot更新
```
